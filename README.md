# Decision-Helper-Website
A smart frontend web app that helps users make better life decisions using logic, clarity, and psychology instead of guesswork.

#✨ Features

Compare two options side-by-side
Decision confidence score (%)
Emotion vs Logic balance meter
Regret probability indicator
Clear explanation & action plan
Save decisions (localStorage)
Dark / Light mode
Mobile-friendly design

#🛠️ Tech Stack

• HTML 
• CSS 
• JavaScript
